Access IMPACT on Your WiFi Network

IMPACT is a single HTML file. To share it on your home WiFi network, serve it with any local HTTP server:

Mac / Linux (Python 3) cd /path/to/impact-folder
python3 -m http.server 8000

Then anyone on WiFi can visit: http://YOUR_IP:8000

Windows (Python) cd \path\to\impact-folder
python -m http.server 8000

Then visit: http://YOUR_IP:8000

Using Node.js npx serve -p 8000
Find your IP address:
• Mac: ifconfig | grep "inet " (try 192.168.x.x)
• Windows: ipconfig → IPv4 Address
• Linux: hostname -I

You can also drag index.html into any browser to use it locally. No server needed for personal use.
